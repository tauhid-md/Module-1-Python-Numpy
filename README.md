# Module 1 – Vectors using NumPy

This repository contains my solved **Module 1 NumPy worksheet**. The notebook covers basic NumPy array operations and matrix calculations using Python.

## Topics Covered

- Creating NumPy arrays
- Vector addition and subtraction
- Scalar multiplication
- Element-wise multiplication using `np.multiply()`
- Reshaping arrays with `reshape()`
- Matrix multiplication / dot product using `np.dot()`
- Transpose of an array
- Matrix inverse using `np.linalg.inv()`
- Rounding results using `np.round()`
- NumPy universal functions (ufuncs): `sqrt()`, `square()`, and `exp()`

## Tools and Technologies

- Python
- NumPy
- Google Colab / Jupyter Notebook

## How to Run

1. Download `Module_1_NumPy_Worksheet_Solved.ipynb` from this repository.
2. Open [Google Colab](https://colab.research.google.com/).
3. Select **File → Upload notebook** and upload the downloaded `.ipynb` file.
4. Run the cells from top to bottom using **Shift + Enter**.

NumPy is imported in the notebook, so no separate installation is normally required in Google Colab.

## Notes on Worksheet Corrections

- The dot product of `[22, 33, 44]` with its transpose is **3509**. The worksheet's listed expected output `3059` is an arithmetic typo.
- The worksheet says to use prime numbers from 1 to 23. Since **1 is not a prime number**, the matrix uses the nine primes `2, 3, 5, 7, 11, 13, 17, 19, 23`.
